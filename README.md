# Nordic Travel AI

Nordic Travel AI is a lightweight AI-powered travel planning web application focused on Finland and Nordic destinations.
It demonstrates how a local Large Language Model (LLM) can be integrated into a simple web system to generate realistic travel itineraries in real time.

---

## Project Overview

This project was developed as part of an academic exploration of:

* AI in software development
* LLM integration in web applications
* Real-time streaming responses
* Practical travel planning automation

The system allows users to input a travel request (e.g., "Plan a 7-day Finland trip") and receive a structured itinerary generated by a local AI model.

---

## Key Features

* **Local AI Model (Ollama)**

  * Runs fully on local machine
  * No external API cost
  * Privacy-friendly

* **Streaming Response (Real-time Output)**

  * AI responses appear progressively (like ChatGPT)
  * Improves user experience and perceived speed

* **Markdown Rendering**

  * AI outputs are formatted with headings, lists, and emphasis
  * Clean and readable travel plans

* **Nordic-focused Travel Logic**

  * Helsinki city trips
  * Lapland routes
  * Family travel scenarios

* **Modern UI Design**

  * Aurora-inspired dark theme
  * Glassmorphism effects
  * Clean layout for demo and presentation

## Tech Stack

### Backend

* Python
* Flask

### Frontend

* HTML / CSS / JavaScript
* Marked.js (Markdown rendering)

### AI

* Ollama (local LLM runtime)
* Model example: `qwen`

---

## System Architecture

User Input → Flask Backend → Ollama (Local LLM) → Streaming Response → Frontend Rendering

* The frontend sends a request to `/generate_stream`
* Flask calls the local Ollama model
* Response is streamed chunk by chunk
* Frontend renders output in real time using Markdown

## Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/your-username/nordic-travel-ai.git
cd nordic-travel-ai
```

---

### 2. Install dependencies

```bash
pip install flask
```

---

### 3. Install and run Ollama

Download Ollama:

https://ollama.com/

Run a model (example):

```bash
ollama run qwen
```

---

### 4. Start the application

```bash
python app.py
```

---

### 5. Open in browser

```text
http://127.0.0.1:5000
```
